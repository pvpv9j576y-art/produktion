❓ Wie funktioniert die JSON-Datei?

📁 Die Daten werden in einer JSON-Datei gespeichert — nicht im Browser.
Sie bestimmen selbst wo die Datei liegt: auf dem Desktop, einem Netzlaufwerk, USB-Stick oder OneDrive.
🆕 Neu starten
Klicken Sie auf „Neue Datei" → geben Sie einen Namen ein → eine leere JSON-Datei wird erstellt und heruntergeladen. Speichern Sie diese an einem festen Ort (z.B. Netzlaufwerk).
📂 Bestehende Datei öffnen
Klicken Sie auf „JSON öffnen" → wählen Sie Ihre gespeicherte .json Datei aus → alle Aufträge werden geladen.
💾 Speichern
Nach jeder Änderung erscheint der orangene Speichern-Button oben. Klicken → die aktualisierte JSON-Datei wird heruntergeladen → alte Datei ersetzen (gleicher Name, gleicher Ordner).
🔗 Mehrere Rechner / Netzlaufwerk
Legen Sie die JSON-Datei auf ein Netzlaufwerk das alle Mitarbeiter sehen können. Jeder öffnet die Datei, arbeitet darin, und speichert sie wieder am selben Ort.
⚠️ Wichtig: Immer nur eine Person gleichzeitig bearbeiten. Die zuletzt gespeicherte Version gewinnt. Für gleichzeitige Bearbeitung wäre eine Datenbank nötig.
📋 JSON-Datei Format (Beispiel):
{ "version": "1.0", "exportedAt": "2024-...", "auftraege": [ { "id": "...", "auftragNr": "AUF-001", ... } ] }
